# 有意变化与兼容边界

- 全量不再清空输出目录。仅处理本任务记录拥有的文件；用户新增/修改文件保留，冲突明确报错。被筛选规则排除的旧文件暂保留；真正源文件删除进入隔离区，7 天后过期，可在任务卡恢复。
- 写入 intent 与 hash 对账支持替换后进程中断；远端 rename/move/upload 检查点对不明确结果先读取确认，不盲目重复写。
- 新密码 bcrypt、随机 JWT secret、会话撤销；旧 MD5 导入后首次登录升级。前端日志需要登录，遥测关闭。
- 旧 dev 增加的季目录改名和散放电影整理保留；设计 main 的 autoRenameMedia 作为默认关闭的显式选项恢复。
- Quartz 使用兼容引擎，五字段沿用旧控制器转换规则（星期数字是转换后的 Quartz 语义）；建议使用 MON/TUE 等名称避免歧义。新实例按本机时区，旧导入按 Asia/Shanghai，调度不追补停机期间每次运行。
- 数据层采用 SQLite JSON records + 独立输出归属/journal 表，不需要外部 DB。保留旧 DTO 字段；旧任务导入停用、重复导入幂等。
- 正则用 regexp2 支持旧命名捕获/lookaround，单次 100ms 限时。完整 Java 正则语法及所有历史样本尚未穷举。
- NFO 保留标题、年份、剧情、评分/票数、时长、类型、制作方、海报地址及外部 ID，新增 uniqueid 和集级 NFO；XML 缩进及生成时间不是逐字节兼容契约。
- 日志最大 10 MiB 轮换，保留至多 5 份归档；保留天数设置用于过期清理。版本查询改为本 fork。
- 构建和运行依赖分离：构建需要 Node/Go，运行只需 Go 二进制。签名/公证需要持有人的证书，默认发行 unsigned 包。

验证映射见 contracts/coverage.json；implemented 表示有真实实现，不代表每一条路由的全部异常组合已完成 Java 差分。
