# 电影目录、识别和画质筛选

电影任务递归扫描配置的 OpenList 根目录。视频可以直接位于根目录，也可以位于分类、合集、电影名、画质等任意层级的子目录内；发现一个视频后仍继续扫描其他子目录。合法视频扩展名沿用系统设置。电影的“跳过不规范目录”不再以目录深度判定非法，电视剧的季目录检查保持不变。

## 任务设置

- **电影 STRM 命名**：默认为标准命名。使用 `片名 (年份) [tmdbid-ID]/片名 (年份) [tmdbid-ID].strm`；未知年份或 ID 不会凭空补入。可选择保留源目录和文件名。已有自定义重命名正则优先。
- **同一电影的多个片源**：默认只生成最佳画质版本，也可选择保留所有版本。相同片名与年份（或同一明确 TMDB ID）的不同清晰度片源参与比较。缺少年份和 ID 时仅在同一个源目录内去重，无法识别的文件不自动合并。
- **跳过 sample、预告片、花絮**：默认开启。根据明确目录名或文件名后缀过滤，不按文件大小删除；可关闭。
- **需要刮削**：配置 TMDB 后生成与 STRM 同名的 NFO，包含正式片名、年份和 TMDB uniqueid。海报使用同名 `-poster` / `-fanart` 文件，避免同目录多部电影串片。

任务卡片中的 **画质筛选预览** 会按已保存设置扫描，显示每组保留与过滤的源路径，不修改文件。预览结果是扫描时的快照；执行时重新扫描并决策。

## 识别实例

源路径：

```text
/电影/求救信号 Mayday (2026)/
  Mayday.2026.2160p.ATVP.WEB-DL.DDP5.1.Atmos.DV.HDR.H.265.mkv
```

搜索：`Mayday`，年份：`2026`。标准输出：

```text
Mayday (2026)/
  Mayday (2026).strm
  Mayday (2026).nfo          # 启用并成功完成刮削时
  Mayday (2026)-poster.jpg   # TMDB 有对应图片时
```

STRM 内容仍指向原始 OpenList 视频 URL，签名与 URL 编码保留。文件名解析不等于真实电影已匹配；如果源文件年份错误或 TMDB 暂无影片，应在手动刮削中核对并指定影片 ID。

文件名优先用于识别；`movie.mkv`、`正片.mkv` 等无有效片名时，向上查找有意义的电影目录，跳过画质目录。只去掉视频扩展名，不再把点分隔的目录片名截断。支持点／下划线分隔、常见发布标签、中英双语搜索、年份、TMDB 标记，以及 1917、2001 等数字片名。多个 TMDB 候选相同时要求明确选择，不静默采用第一条。目录包含多部电影时，手动整理会要求选择其中一部，不把整个合集重命名成同一影片。

## 最佳画质规则

依次比较以下信息，前项优先：

1. 分辨率：4320p / 8K > 2160p / 4K > 1440p > 1080p > 720p > 更低分辨率。
2. 动态范围：Dolby Vision > HDR10+ > HDR10 / HDR / HLG > SDR 或未知。
3. 片源：REMUX > BluRay / BDRip > WEB-DL > WEBRip > HDTV / DVDRip > 未知。
4. 编码：AV1 > H.265 / HEVC > H.264 / AVC > 未知。
5. 文件大小；相同条件下按源路径稳定决胜，避免每次扫描来回切换。

以上是基于文件名／目录标签和 OpenList 文件大小的确定性规则，不读取完整视频进行画质测量。分辨率优先不代表每个 4K 压制一定优于 1080p 原盘。不同导演剪辑版、加长版等，以及 CD1/CD2、Part1/Part2 分段分别保留。未知标签可能需要手工修正或选择保留全部。

## 过滤和恢复

普通 STRM 任务不会删除 OpenList 原视频。未选中的低画质版本不生成 STRM；此前由本任务生成、仍未被用户修改的重复 STRM 及关联元数据移入现有隔离区。切换为保留全部可以重新生成。新增更好版本时，同名 STRM 更新为更好片源；最佳源删除后可回退到剩余片源。

目录扫描失败、输出写入失败或刮削未完整成功时不清理旧输出。未认领文件和外部修改过的文件继续保留。不同任务的输出目录不得重叠，遵循原有配置检查。

显式开启“自动整理远端媒体”仍会按原有选项重命名／移动远端媒体；电影整理仅处理入选版本，并保留质量、剪辑和分段标签。建议先用预览核对识别信息。此功能不会永久删除低画质原视频。
