# OStrm project website

Published at https://moersity.github.io/ostrm/ from the `gh-pages` branch root using GitHub Pages. This branch contains only the project website; application code and releases remain on `main`.

Edit `index.html`, `style.css` and `site.js`, preview with `python3 -m http.server 3188`, then push this branch. No build dependencies. Asset URLs are relative so the `/ostrm/` project path works. Download buttons resolve assets from this fork's latest stable GitHub Release, with a Release-page fallback if the API is unavailable.

The application name and logo originate from OStrm. This site retains the original project's attribution and GPL-3.0-or-later license.
